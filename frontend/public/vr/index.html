🥽 Meta Quest 3 ile Bağlantı
  1. Meta Quest 3 başlığınızdan Meta Quest Browser tarayıcısını açın.
  2. Adres çubuğuna canlı web adresini yazın: https://ogretmenlerodasi.info/vr
  3. Doğrudan güvenli SSL bağlantısı ile açılır (aynı Wi-Fi veya APK kurulumu gerekmez).
  4. Aşağıdaki parlayan ENTER VR butonuna dokunarak İzmir Torbalı BİLSEM sanal evrenine geçin!
🎮 Kontroller: Quest 3 kontrolcüsünün Trigger veya Grip tuşu ile kartları tutup Cevap Yuvasına bırakabilirsiniz. PC'de fare ile tıklayıp sürükleyebilirsiniz.
