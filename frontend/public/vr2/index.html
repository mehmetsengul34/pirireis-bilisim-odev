🥽 Meta Quest 3 ile Bağlantı
  1. Meta Quest 3 başlığınızdan Meta Quest Browser tarayıcısını açın.
  2. Adres çubuğuna canlı adresi yazın: https://ogretmenlerodasi.info/vr2
  3. Doğrudan güvenli SSL bağlantısı ile açılır (herhangi bir APK kurulumu gerekmez).
  4. Ekranın altındaki parlayan ENTER VR butonuna dokunarak Sayı Adası'na ışınlanın!
🎮 Kontroller: Quest 3 kontrolcüsünün Trigger veya Grip tuşu ile meyveleri, taşları, kristalleri ve pasta dilimlerini tutup bırakabilirsiniz. PC'de fare ile tıklayıp sürükleyebilirsiniz.
